# C++ Language Learning

A structured C++ learning repository covering the language from **fundamentals to advanced concepts**, with practical examples and programs for hands-on learning.

## 📚 Topics Covered

### 🔰 Fundamentals

* Introduction to C++
* Program Structure
* Variables and Constants
* Data Types
* Operators
* Input and Output
* Conditional Statements
* Loops
* Functions

### 📦 Core C++

* Arrays
* Strings
* Pointers
* References
* Dynamic Memory
* Structures
* Enumerations
* Namespaces
* File Handling

### 🧩 Object-Oriented Programming

* Classes and Objects
* Constructors and Destructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Function Overloading
* Operator Overloading
* Virtual Functions

### 🧰 STL

* `vector`
* `array`
* `list`
* `deque`
* `stack`
* `queue`
* `priority_queue`
* `set`
* `map`
* Iterators
* Algorithms

### 🚀 Advanced C++

* Templates
* Exception Handling
* Lambda Expressions
* Smart Pointers
* Move Semantics
* RAII
* Modern C++ Features

## 🎯 Purpose

This repository is created for learning and practicing **C++ programming through examples, exercises, and practical programs**, progressing from beginner concepts to advanced C++.

## 🛠️ Requirements

* C++ Compiler (GCC/G++)
* Linux / Unix-based system
* Basic programming knowledge
